NIHILIST PENGUIN: Meaning Is Optional

A small original Pygame Zero platformer made for the supplied Python LVL1 task.

RUN
1. Install Pygame Zero: pip install pgzero
2. Open a terminal in this folder.
3. Run: pgzrun game.py

CONTROLS
A / D or Left / Right: move
Space: jump
Esc: return to menu
Mouse: menu buttons

GOAL
Collect all 5 Meaning Shards, avoid the roaming Doubt enemies, then reach the exit on the far right.
You have 3 lives.

ASSETS
All PNG and WAV assets in this project were created specifically for this project.
No external runtime libraries are used by game.py beyond Pygame Zero and Python's allowed modules math/random.

THEME
A nihilist penguin crosses a bleak frozen world while collecting fragments of meaning.
The humor is intentionally absurd and non-graphic.
